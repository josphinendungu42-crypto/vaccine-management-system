# Vaccine Management System

A web application to manage patient vaccine records, appointments, and vaccine inventory.

**Tech Stack:** TypeScript, Vite, HTML, CSS, JavaScript

**Features I Built:**
- Patient registration and records
- Vaccine inventory tracking  
- Basic user authentication

**How to Run:**
1. `npm install`
2. Add `GEMINI_API_KEY` in `.env.local`
3. `npm run dev`

Built as part of my IT studies at Kiriri Women’s University of Science and Technology.
